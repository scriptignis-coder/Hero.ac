# HeRoShield V13 — Missing license RPC fix

The API calls `public.hs_claim_account_license(p_hash text, p_discord text)`.

## Required database step
1. Back up your Supabase database.
2. Open Supabase SQL Editor in the SAME Supabase project configured in Render.
3. Execute `FIX-LICENSE-DATABASE-V13.sql` as a single query. Check for actual `Success`, not just a successful SELECT.
4. Run this verification query:

```sql
SELECT p.proname, pg_get_function_identity_arguments(p.oid) AS arguments
FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
WHERE n.nspname='public' AND p.proname='hs_claim_account_license';
```

Expected: one row with `p_hash text, p_discord text`. If 0 rows, the function was not installed in the project.

5. Confirm Render environment `SUPABASE_URL` points to the same Supabase project; restart the Render service and retry activation.

The migration leaves the original `public.hs_licenses` table untouched.

**Security:** Never paste the Supabase service role key or Discord bot token into screenshots or chat.

**Limitations:** This corrects the missing RPC/schema mismatch. Live activation still depends on a license generated by the current bot and on correct Supabase configuration. It has not been tested against your live database.
