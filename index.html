FAQ

Questions.

Is it safe for the player?
Yes. The scanner is read-only: it installs nothing, changes nothing, and never reads passwords, cookies, the Discord login or messages. It takes no screenshots.
Does it still work if the cheat was deleted?
Yes. Windows keeps traces of what ran and what was deleted — execution history, the file journal, Jump Lists, the recycle bin and USB history. That is what HeRo Shield reads.
Why does Windows sometimes warn about the scanner?
It reads the same places antivirus AI watches closely, and it is a new program. No antivirus has found real malware in it. The player only has to allow this one file — never turn protection off.
How long does a scan take?
A few minutes, depending on the PC and the size of the drives.
Can several staff members use one license?
Yes. One license for your staff team; access is controlled with permissions on the dashboard.
Is there a free trial?
Yes, 7 days for FiveM servers. Open a Free trial ticket in our Discord.
