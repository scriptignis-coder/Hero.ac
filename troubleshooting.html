✧ Troubleshooting

HeRoShield doesn't open?

Most startup and connection issues can be resolved by checking these two common requirements. Follow the steps below in order.

Keep the scanner open during verification

Do not close or interrupt HeRoShield while the forensic process is running. Wait until the final report is generated.

Keep it open
⚙
Runtime dependency

Microsoft .NET Framework 4.8

The scanner (v4.2 and newer) uses .NET Framework 4.8, which is already part of Windows 10 and 11. Install or repair it only if the scanner does not start. Older scanners (before v4.2) need the .NET 8 Desktop Runtime x64 instead — or simply download the scanner again from a new PIN link.

↓ Download .NET Framework 4.8 ↗

Recommended procedure · 01

Follow these steps in order.

01Right-click the scanner → Run as administrator (it needs admin rights to read the PC).
02If Windows says “Windows protected your PC”: More info → Run anyway.
03Still nothing: install / repair .NET Framework 4.8 from Microsoft and restart Windows.
04If an error appears, send staff %TEMP%\HeRoShield-startup-error.log.
☁
Connection troubleshooting

Cloudflare WARP

If HeRoShield opens but cannot connect or authenticate, check your internet connection first. Cloudflare WARP is an optional network troubleshooting step, not a required dependency.

↓ Download Cloudflare WARP ↗

Optional procedure · 02

Try this only if connection issues persist.

01Check your internet connection and try again.
02If needed, download and install Cloudflare WARP.
03Open WARP and enable the connection.
04Reopen HeRoShield and retry authentication.
🛡 Keep Windows Defender enabled

You do not need to disable Microsoft Defender or Windows Security to run HeRoShield.

✓ Still having problems?

Restart the scanner, check the PIN and license, then open a support ticket in our Discord server.

Only download installers from official Microsoft and Cloudflare websites. Cloudflare WARP may not resolve every network problem.
